BriefCase

Point the extension at your local sidecar and paste your auth token.

Default is http://127.0.0.1:8989. Change only if you customized the port in settings.yaml.
Run cat ~/.briefcase/sidecar_token in a terminal to retrieve it. Rotating: delete the file and re-run install.sh.

Theme

Applied instantly across the side panel and options page.

How to use

  1. Right-click selected text on any page and choose BriefCase → Send to BriefCase....
  2. Edit content, paste a specific URL if you have one, check what this needs (Jira ticket / code review / search around / calendar), add context, send.
  3. Next time you open Kit, it will see the new item and offer to triage it.
  4. You decide per-item: brain dump, new initiative, ThriveNote, daily note, or discard.

Keyboard shortcut

Set a shortcut at chrome://extensions/shortcuts to open the side panel directly from a selection — useful on pages like Google Docs that hijack right-click.
